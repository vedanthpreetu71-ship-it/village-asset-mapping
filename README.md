# Village Asset Mapping System

A beginner-friendly project to map essential community assets like schools, hospitals, water tanks, roads, and public facilities on an interactive map.

## Features
- Interactive map with location markers
- Add new community assets
- Filter assets by category
- See key details for each location
- Simple dashboard with summary stats
- Responsive layout for desktop and tablet

## Tech Stack
- React
- Vite
- Leaflet and React Leaflet

## Project Goal
This system helps local communities and planners track and manage important village resources using a GIS-style interface.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the app locally:
   ```bash
   npm run dev
   ```

3. Open the application in your browser at:
   ```bash
   http://localhost:3000
   ```
